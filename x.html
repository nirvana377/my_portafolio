🔥 Función útil del día: Cómo debounce en JavaScript puede salvar tu app de mil llamadas innecesarias a la API.

javascript
const debounce = (fn, delay) => {
  let timeoutId;
  return (...args) => {
    clearTimeout(timeoutId);
    timeoutId = setTimeout(() => fn(...args), delay);
  };
};
